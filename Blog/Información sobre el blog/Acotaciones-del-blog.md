## SOBRE EL FORMATO DEL BLOG: 
El blog se realizara en la plataforma github, esta desición se toma para seguir la linea del semestre pasado, en el cual, tambien fue realizado en github. 

Además asi, todos los integrantes podemos contar con acceso al blog, además, es más simple compartirlo con el equipo docente.

Al ser Github una plataforma principalmente para compartir codigos, para realizar el blog se utilizara el formato .md, el cual, es el más accesible y sencillo de utilizar dentro de la plataforma. 
Dicho esto destacamos que el formato .md es sumamente similar al formato utilizado por la IA, en sus respuesta. Como AmbientEssence destacamos que no se utilizo IA para llevar a cabo este blog. Solo se utilizo para configuraciones de formato en la aplicación, las cuales eran desconocidas por los miembros, se utilizo para aprender a utilizar el formato .md en Github, posterior a eso no se utilizo la IA para ningun a otro fin, por lo cual solo es una coincidencia de formato.
Como grupo nos comprometemos a utilizar la IA de forma ética, esto involucra aceptar el uso de IA en caso de ser utilizada para diversos fines.
