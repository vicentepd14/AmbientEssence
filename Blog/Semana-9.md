## Catedra:
Durante la catedra se presento un avance del prototipo, el prototipo actual consiste en una placa conectada a un sensor de humedad que activa un led cuando la humedad es critica
en este diseño inicial el led remplaza la valvula solenoide, esto para evitar problemas de voltaje y simplificar el prototipo inicial. 
Además el prototipo cuenta con un sensor de movimiento con el objetivo de intentar un sistema que logre espantar a la fauna evitando que dañen el sistema de regadío. 
Se presento este prototipo y se intento idear una solución al problema secundario del transporte. 
El grupo llego a la conclusión de que el problema principal del grupo es la optimización de agua para impulsar un crecimiento optimo de las plantas. Se abordara 
como problema secundario el transporte de agua. En base a esto se llego a una solución para el transporte el cual consiste en incorporar un estanque de agua junta al prototipo,
el cual debe ser cargado de forma manual, pero la idea es que gracias a la optimización esta carga dure un tiempo evitando asi constantes cargas.
